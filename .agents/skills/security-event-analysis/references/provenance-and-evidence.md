# Provenance and evidence

## Raw and parsed representations

Raw payload/text, source rows, parsed fields, and analyst notes have different provenance. Retain each supplied representation and cite its E### record. Do not overwrite raw data with normalized fields or repair a conflict by choosing the more plausible value.

## Evidence records

Use the shared evidence schema. Keep the source, received time, raw content or stable raw reference, original timestamp if supplied, and extracted facts. Continue E### identifiers after existing investigation evidence. A separate source record receives a separate evidence ID even if it is an exact duplicate.

## Bounded findings

An evidence mismatch can support a high-confidence statement that the two supplied values differ. It does not by itself establish a parsing defect, false positive, compromise, maliciousness, or root cause.
