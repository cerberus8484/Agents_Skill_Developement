Skill‑Bibliothek

Deine eigenen Skills — und wie jeder Skill zu den Agenten gehört. Ein Skill ist ein Regelwerk/Playbook, das sich in den Kontext lädt (das Wie/Was). Ein Agent ist der ausführende Worker (das Wer). Agenten wenden die für ihre Aufgabe passenden Skills an.

→
