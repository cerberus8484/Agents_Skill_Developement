Agent‑Dokumentation

Was jeder Sub-Agent genau macht, wann man ihn einsetzt, welche Tools er nutzt und nach welchen Standards / Normen er arbeitet.

*

Technische Domänen-Standards (OWASP, PEP 8, WCAG, OpenAPI, OSI/RFCs, SQL …) wendet der jeweilige Agent direkt an. Übergreifende Compliance-Frameworks — ISO 27001, NIS2, DSGVO/GDPR — sind mit * markiert: sie kommen in deinem Setup aus den security-/dsgvo-/ccd-Skills und den Projekt-Standards; der security-reviewer prüft die technischen Kontrollen dagegen. Ein generischer Agent „zertifiziert“ keine Norm — er arbeitet gegen ihre Regeln.  Welche Skills welchen Agenten schärfen, steht in der Skill-Bibliothek →
