# Scope and evidence

**STANDARD:** WCAG 2.2 has testable success criteria and defines conformance for full web pages. It is not a component-only certificate.

**FRAMEWORK RECOMMENDATION:** Treat accessibility as a design-system concern, while handing complete audit claims to qualified testing across real pages, states, devices, and assistive technologies.

Design system: shared principles, tokens, components, guidance, and governance. Component library: implementation collection. Tokens: named design decisions. Accessibility: access to content and operation. UX: user outcomes and research. Visual design: presentation. Brand: identity governance.

Source: https://www.w3.org/TR/WCAG22/
